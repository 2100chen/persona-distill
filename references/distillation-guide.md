# 蒸馏维度说明 & 调优技巧

本文件给 Skill 作者/维护者看：解释每个蒸馏维度在抓什么、怎么判读、怎么调。

## 蒸馏的 10 个维度

| 维度 | 抓什么 | 判读要点 |
|---|---|---|
| 语言风格 | 正式/随意、书面/口语、简洁/啰嗦 | 看平均句长、是否用书面词 |
| 口头禅/高频词 | 反复出现的词、感叹词、自称 | 必须是真实高频，不能编 |
| 句式习惯 | 疑问句多不多、反问、省略主语 | 反映互动方式 |
| 语气情绪 | 积极消极、温和毒舌、急躁稳重 | 决定回复基调 |
| 回复逻辑 | 先共情再建议？直接给结论？ | 决定处事方式 |
| 标点 emoji | ！！/。。/波浪号、emoji 频率 | 强风格指纹 |
| 开场/收尾 | 怎么起头、怎么结束对话 | 高频套路 |
| 价值观/雷区 | 在意什么、反感什么 | 避免踩雷 |
| 风格锚点 | 3-5 句最具代表性原话 | 逐字引用，用于核对 |
| Do/Don't | 模仿时的正反指令 | 给 agent 的可执行规则 |

## 支持的聊天记录格式

脚本自动识别下列格式（UTF-8 优先，回退 GBK）：

**A. 微信/QQ 导出（带时间戳，消息可能跨多行）**
```
2024-03-01 10:23:45 张三
在吗，有点事问你

2024-03-01 10:24:10 李四
说
```

**B. QQ 导出（昵称带 QQ 号）**
```
2024-03-01 10:23:45 张三(123456)
在吗
```

**D. JSON 导出（微信 WeChatMsg / 留痕 / QQ exporter，多 schema 自动识别 sender/text 字段）**
```
[{"senderDisplayName":"张三","text":"在吗"},{"nickname":"张三","content":"说话"}]
```

**C. 简单「昵称: 内容」**
```
张三: 在吗
李四: 说
```

识别逻辑：先匹配时间戳行（提取说话人），否则匹配 `昵称: 内容`。
若 `--alias` 未指定，脚本默认取**出现最多的说话人**并打印 Top5 供核对。

## 调优技巧

- **样本不够像**：增大 `--budget`（默认 10000 字符上限），或合并多个时期的记录。
- **口头禅抓偏**：脚本会同时输出 Top 高频词统计作为佐证，可与模型结论交叉核对。
- **风格太淡/太夸张**：在生成后用 Edit 微调「如何模仿」段，不必重跑全量蒸馏。
- **多人记录**：务必用 `--alias` 指定目标，否则会蒸馏成混合风格。
- **隐私**：源记录可能含他人隐私，配置文件只写目标人物的风格特征，不搬运他人原话。

## 关于「激活人格」

`switch_persona.py <name>` 会把选中人格写入 `data/personas/ACTIVE.md`，并提示 agent 后续回复采用此口吻。
这是本 skill 自身的能力（让 agent 在对话中扮演该人物），不依赖其它 skill。`--clear` 可恢复默认口吻。
